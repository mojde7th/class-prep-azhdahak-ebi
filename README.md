# آماده‌سازی کلاس · اژدهاک و شب مرد تنها

راهنمای تعاملی برای تمرین برخوانی پنج صفحهٔ اول **اژدهاک** (بهرام بیضایی) و ترانهٔ **شب مرد تنها** (ابی).

## اجرا

```bash
npm install
npm run dev
```

اپ روی پورت `43127` بالا می‌آید:

[http://127.0.0.1:43127](http://127.0.0.1:43127)

## محتوا

- نشانه‌گذاری **با اوج / بلند**، **کشش**، **نرم**، و **مکث**
- تلفظ واژه‌های سخت
- پلان سریع قبل از کلاس
- متن کامل ترانه با لحن و کشش

## ساخت نسخهٔ نهایی

```bash
npm run build
npm run preview
```
