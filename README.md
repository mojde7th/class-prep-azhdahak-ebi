# آماده‌سازی کلاس · اژدهاک و شب مرد تنها

راهنمای تعاملی هم‌سطح برای دو متن کلاس:

1. پنج صفحهٔ اول **اژدهاک** (بهرام بیضایی)
2. متن کامل **شب مرد تنها** (ابی)

هر دو با همان قالب بندبه‌بند: اوج، کشش، نرم، مکث، تلفظ.

## اجرا

```bash
npm install
npm run dev
```

اپ روی پورت `43127` بالا می‌آید:

[http://127.0.0.1:43127](http://127.0.0.1:43127)

## محتوا

- دو کارت انتخاب بالای صفحه برای جابه‌جایی سریع بین دو متن
- نشانه‌گذاری **با اوج / بلند**، **کشش**، **نرم**، و **مکث**
- واژه‌نامهٔ جدا برای اژدهاک و ترانه
- پلان سریع قبل از کلاس

## ساخت نسخهٔ نهایی

```bash
npm run build
npm run preview
```
